# 📰 NewsHub – News Mobile Application

NewsHub is a Flutter-based mobile application for browsing the latest news from multiple sources
and categories. The app supports both **Arabic and English languages**, includes search functionality,
and provides a smooth browsing experience using pagination.

## 📱 Overview

NewsHub allows users to stay updated with the latest news by browsing articles
from various sources and categories. The app focuses on performance, simplicity,
and accessibility with multilingual support.

---

## 🚀 Features

- Browse news by category
- Browse news by source
- Search for news articles
- Arabic & English language support
- Pagination for smooth scrolling
- Clean and responsive UI
- Real-time news updates

## 🌐 API Integration

- Integrated **NewsAPI.org**
- Fetches real-time news data
- Supports multiple sources and categories
- Handles API responses efficiently using RESTful APIs

---

## 🌍 Localization

- Supports **Arabic** and **English**
- Dynamic language switching
- Optimized UI layout for RTL and LTR languages

- Articles loaded incrementally

- Prevents excessive API calls

## ⚙️ Setup

### 🧰 Requirements

- Flutter SDK **3.24.3** (stable channel)
- Dart SDK **3.5.3**
- Android Studio (Ladybug or newer)
- Minimum SDK: flutter.minSdkVersion
- Target SDK: flutter.targetSdkVersion
- Android emulator or physical Android device

Clone the repository:
